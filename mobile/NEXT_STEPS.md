# Gemini explanation integration

This build keeps the deterministic recommendation engine as the source of truth and adds Gemini explanations for the top three results.

## Supabase deployment

The matching Supabase ZIP contains `supabase/functions/explain-recommendations/index.ts`.

The `GEMINI_API_KEY` must remain a Supabase secret. Do not put it in the Expo `.env` file.

From the project root (the directory that contains the `supabase` folder), deploy:

```powershell
npx supabase functions deploy explain-recommendations
```

If the CLI says the project is not linked, run `npx supabase link --project-ref YOUR_PROJECT_REF` first.

## Mobile verification

From `mobile`:

```powershell
npm install
npx tsc --noEmit
npx expo start --clear
```

Sign in, enter a group, and open recommendations. The deterministic rankings should appear first. The top three cards should then show `Why this fits your group` text generated by Gemini.

If Gemini fails, the ranking remains usable and the UI displays an explanation-unavailable fallback instead of breaking the recommendation flow.
